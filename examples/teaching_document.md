# 初中数学·二次函数 讲义（第 2 章）

## 2.1 二次函数的概念

### 定义

一般地，形如 y = ax² + bx + c（a、b、c 是常数，且 a ≠ 0）的函数，叫做二次函数。其中 x 是自变量，a、b、c 分别是函数解析式的二次项系数、一次项系数和常数项。

### 理解要点

判断一个函数是否为二次函数，关键看：
1. 整理后是否为整式
2. 自变量的最高次数是否为 2
3. 二次项系数 a 是否不为 0

注意：y = ax² + bx + c 中若 a = 0，则它是一次函数（b≠0 时）或常函数（b=0 时），不是二次函数。

## 2.2 二次函数的图象与性质

### 抛物线的开口方向

二次函数 y = ax² + bx + c 的图象是一条抛物线。
- 当 a > 0 时，抛物线开口向上，顶点是最低点
- 当 a < 0 时，抛物线开口向下，顶点是最高点
- |a| 越大，抛物线开口越小；|a| 越小，抛物线开口越大

### 顶点坐标与对称轴

配方可得 y = a(x - h)² + k 的形式（顶点式），其中顶点坐标为 (h, k)，对称轴为直线 x = h。

h = -b/2a，k = (4ac - b²)/4a

### 考点提示

中考常考：根据 a 的符号判断开口方向、根据顶点式写出对称轴和最值。这是本章必考点，选择题和填空题高频出现。

## 2.3 例题解析

### 例题 1（基础题）

已知二次函数 y = x² - 4x + 3，求它的顶点坐标和对称轴。

**解析**：
配方：y = x² - 4x + 3 = (x² - 4x + 4) - 4 + 3 = (x - 2)² - 1

所以顶点坐标为 (2, -1)，对称轴为直线 x = 2。

### 例题 2（提高题）

已知抛物线 y = ax² + bx + c 经过点 (0, 3)、(1, 0)、(3, 0)，求解析式。

**解析**：
因为抛物线经过 (1, 0) 和 (3, 0)，可设交点式 y = a(x - 1)(x - 3)。
代入 (0, 3)：3 = a(0-1)(0-3) = 3a，得 a = 1。
所以解析式为 y = (x - 1)(x - 3) = x² - 4x + 3。
