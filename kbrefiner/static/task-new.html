知序 KBRefiner

让 RAG 知识库更干净、更可靠

KBRefiner 是一条面向 RAG 场景的文档质检流水线：自动解析、智能清洗、结构化分块、QA 对生成与敏感信息检测，帮助团队把原始文档转化为高质量、可检索、可落地的知识资产。

  • 四段式流水线：Clean → Chunk → QA → Tag 全链路处理
  • LLM 深度质检：基于 DeepSeek 的清洗、纠错与标签推理
  • 断点可恢复：阶段校验、重试与并行执行，任务可控可追溯
